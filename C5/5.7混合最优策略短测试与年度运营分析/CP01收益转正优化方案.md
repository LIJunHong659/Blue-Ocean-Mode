# CP01 收益转正优化方案

> 整理日期：2026-08-05  
> 适用口径：基于当前年度在线策略结果、4.8 生命周期成本重算和 V5 边界假设整理。本文用于揭榜挂帅赛题方案优化，不构成可研概算、融资承诺或投资决策。所有 CAPEX、O&M、价格和合同条件仍需用企业一手报价、赛题原文和承购合同校准。

## 1. 核心判断

当前方案不是运营亏损，而是投资边界过重导致项目层亏损。

年度在线调度结果已经证明一件事：在当前模型假设下，6 h 滚动先验-后验策略可以实现全年 ENS=0，并取得正的现金口径运行毛收益。但是，一旦把 CAPEX、固定运维、替换和融资成本放进项目账，收益被重资产年化负担吞掉。

因此，方案不能继续写成“800 MW 源侧、100 MW 电解槽、120 MW 海底算力、200 MW 海缆、80 MW/160 MWh BESS 一次性满配建设”。更可落地的写法应改为：

1. 技术主线保留：多源预测、滚动优化、可靠性-经济性分层调度、极端事件韧性响应。
2. 投资边界收窄：先做轻资产和分期验证，不把所有远期扩展资产一次性计入项目初始 CAPEX。
3. 收入合同化：电力、氢、算力和海洋服务必须从“假设价格”改为“保底量加合同价”。
4. 可靠性分层：刚性负荷用储能和安全约束保障，柔性算力、制氢和外送按边际收益择优运行。

这次回放仿真补了一条更硬的结论：单靠把年化负担压到 88% 还不够过 1.2 门槛；30 MW 模块化制氢可以把经济口径做正，但不能单独继承当前年度台风代理事件的 ENS=0 证据。若要同时保住经济和可靠性，要么保留接近 100 MW 的制氢/储氢能力，要么配等效外部备用。

## 3. 收益转正的硬门槛

项目年度转正的基本公式是：

```text
年度项目净收益
= 年度现金运行毛收益
- 年化资本成本
- 年固定运维
- 年替换准备金
- 保险、税费、退役、平台等未计入成本
```

当前 4.8 生命周期重算中的年化资本和固定负担为：

| 项目 | 当前值 |
|---|---:|
| 年折旧 | 1,188.967 百万元/年 |
| 年融资成本 | 1,588.634 百万元/年 |
| 年固定运维 | 836.811 百万元/年 |
| 年替换准备金 | 440.198 百万元/年 |
| 合计年化负担 | 4,054.611 百万元/年 |

用现金口径算：

```text
当前年度缺口
= 4,054.611 - 480.056
= 3,574.555 百万元/年
```

这说明单纯微调运行策略救不回来。要转正，必须满足以下至少一个条件，最好同时满足：

1. 年化资本和固定负担从 40.55 亿元/年降到不高于 4.80 亿元/年，即下降约 88.2%。
2. 在不降投资的情况下，年度现金运行毛收益从 4.80 亿元/年提高到 40.55 亿元/年，即提高约 8.45 倍。
3. 通过财政支持、示范补贴、共建共享、客户自持资产、分期投产等方式，把本项目实际承担的资产负担移出项目边界。

只靠单一产品涨价的盈亏平衡价不现实：

| 只靠单项收入补缺口 | 粗略盈亏平衡价 |
|---|---:|
| 只靠电力外送 | 约 5,100 CNY/MWh 以上 |
| 只靠氢交付 | 约 815 CNY/kg |
| 只靠算力服务 | 约 22,700 CNY/MWh-CS |
| 只靠海洋服务 | 约 20,000 CNY/MWh 量级 |

这些价格均远高于当前模型锚价，不能作为主要优化路径。真正路径是“降资本负担 + 提高合同收入 + 提高利用率 + 分期建设”。

年化负担下降对转正的影响如下：

| 年化资本及固定负担下降幅度 | 剩余年化负担 | 在当前运行毛收益下仍需新增毛收益 |
|---:|---:|---:|
| 0% | 4,054.611 百万元/年 | 3,574.555 百万元/年 |
| 50% | 2,027.306 百万元/年 | 1,547.250 百万元/年 |
| 70% | 1,216.383 百万元/年 | 736.327 百万元/年 |
| 80% | 810.922 百万元/年 | 330.866 百万元/年 |
| 88% | 486.553 百万元/年 | 6.497 百万元/年 |
| 90% | 405.461 百万元/年 | 已有约 74.595 百万元/年安全垫 |

结论：要把收益变正，方案至少要把本项目实际承担的年化资本和固定负担压到当前的 10% 到 12% 区间，或者在 88% 下降口径下同时做足合同收入；但若还要继承现有年度极端事件 ENS=0，30 MW PEM 不够，必须保留更高制氢/储氢能力或外部备用。

## 5. 优化后的总体方案

建议把项目改写为：

**面向深远海能源岛的多源协同调度与合同化收益闭环验证平台。**

方案重点不再是证明“满配资产堆叠后理论上能多产品输出”，而是证明：

1. 在真实不确定源侧、极端天气和多产品需求下，调度系统能保持关键负荷 ENS=0；
2. 在合同价格、保底量和资产边界约束下，系统能选择正边际收益的产品通道；
3. 资产投入按阶段滚动扩容，只有当上一阶段满足利用率和承购门槛时，才进入下一阶段。

这里要补一句：一期验证的核心不只是“能跑”，而是“能跑正且不丢可靠性证据”；二期制氢不应默认 30 MW 就足以覆盖台风期保供，必须同步给出 100 MW 保供对照或等效备用边界。

### 一期：电力外送主线 + 小型 BESS + 合同化柔性算力

目标：用最少自有重资产验证调度系统、收益闭环和极端事件韧性。

建设边界建议：

1. 源侧不按 800 MW 全额自建计入一期。可采用示范机组、第三方绿电 PPA、已建/拟建风场共享电量或企业内部转供口径。
2. 电力外送优先采用近岸或共享送出边界，不在一期单独背负 200 km、200 MW HVDC 全额 CAPEX。
3. BESS 从“80 MW/160 MWh 固定满配”改为可靠性定容，先满足关键负荷和台风过境安全窗口，再看是否需要扩容。
4. 海底算力不自购 120 MW 设备。改为客户自持 IT 设备，项目方提供绿电接入、冷却、舱体、运维和可中断调度服务。
5. 一期只承诺可中断算力，不承诺刚性算力 SLA。若客户需要刚性 SLA，应由客户支付容量费和备用费。

一期收入结构：

| 收入 | 合同化方式 |
|---|---|
| 电力外送 | PPA 保底电价、绿电溢价、容量或辅助服务收入 |
| 柔性算力 | 容量预约费 + 实际服务费，SLA 罚金封顶并与客户用电等级匹配 |
| 海洋服务 | 关键负荷保障费、应急保供服务费、测试服务费 |

一期转正判据：

```text
一期合同化年度毛收益 >= 一期实际承担年化负担 x 1.2
```

其中 1.2 是安全系数，用于覆盖价格波动、停机、保险、税费和未计入运维。若一期仍按当前全量资产边界核算，则不能宣称收益转正。

### 二期：制氢-储氢-交付扩展

目标：把当前“可运行的制氢链条”改成“有承购、有物流、有现金回款的氢业务”。

当前年度结果中，电解槽全年投入 300,486.066 MWh，按 100 MW 额定容量约等于 3,005 h 满发小时。这个利用小时并不差，问题在于氢价、物流、库存和源侧资本分摊没有合同化。

二期进入条件：

1. 签订氢气或绿色燃料承购协议，明确保底量、价格、交付点、损耗、违约和调价机制。
2. 氢库存只按实际交付确认收入，不再把期末库存估值当现金收益。
3. 电解槽先按 20 MW 到 30 MW 模块化试点，达到利用率和回款门槛后再扩到 100 MW。
4. 储氢容量按船期、管输能力和安全库存动态定容，不按额定产氢 1 h 机械配置。
5. 制氢只吸收低机会成本电量：弃电、低价时段电力、合同约束下必须消纳的绿电。

二期调度规则：

```text
当 氢合同边际收入
> 电力外送机会收入 + 制氢变量成本 + 启停折损 + 储运成本 + 安全库存成本
时，才启动制氢。
```

如果氢承购价不能覆盖以上边际成本，电解槽即使技术上可运行，也不应被写成盈利资产。

### 三期：潮流能、船运氢和规模化海底算力

目标：在一、二期现金流稳定后，把潮流能和海底算力作为增量创新模块，而不是一期盈利基石。

三期进入条件：

1. 潮流能取得场址流速、OEM 功率曲线、可用率、运维船期和 CAPEX 报价后，再从 1 MW 到 5 MW 示范开始。
2. 海底算力必须采用客户自持、设备商共建或长期容量租约。若仍由项目方承担 IT 设备和 5 年替换成本，则不进入扩容。
3. 船运氢必须用船期窗口、装卸能力、损耗、港口接收能力和安全监管成本替换当前假设参数。
4. 三期扩容必须通过多年 8760 h 随机场景，而不是 24 h 或 48 h 片段年化。

三期定位应写成“产业扩展选项”，不写成“当前转正必需条件”。否则方案会重新回到重资产亏损逻辑。

## 6. 合同和商业模式改造

### 电力外送

当前电力外送收入约 2.91 亿元/年，但海缆加站端年化负担约 4.70 亿元/年，还未分摊源侧资本成本。要转正，电力外送不能只按公开电价锚点结算。

建议写法：

1. 引入 PPA 或 CfD：锁定保底电价，避免完全暴露于现货价。
2. 叠加绿电、绿证、碳减排和深远海示范补偿价值。
3. 争取共用送出通道，把海缆和站端从单项目 CAPEX 改为共享基础设施。
4. 对极端天气下的可恢复供电能力收取容量或韧性服务费。

### 氢业务

氢业务最有希望在轻资产边界下接近转正，但前提是合同化。

建议写法：

1. 氢收入只按交付确认，不按期末库存估值确认。
2. 签订 take-or-pay 或 minimum offtake 合同，避免设备利用小时不足。
3. 氢价必须覆盖制氢、压缩、储运、损耗、船期等待和备用成本。
4. 先用模块化 PEM，保留扩容接口，不一次性建满 100 MW。
5. 若氢系统同时承担极端事件保供，不能只按 20 MW 到 30 MW 经济试点定容，需用 8,760 h 回放验证氢转电短缺为 0，或另配等效备用。

### 算力业务

当前自有海底算力模式是最大亏损风险之一。年化负担约 10.37 亿元/年，而当前算力服务收入约 0.80 亿元/年，数量级不匹配。

建议写法：

1. 不把 120 MW 海底算力 IT 设备作为项目方自有资产。
2. 客户自持服务器，项目方收取绿电、冷却、舱体、运维和调度服务费。
3. 算力负荷明确为可中断或分级 SLA，高等级 SLA 单独付容量费。
4. 设备 5 年替换成本由客户、设备商或租赁合同承担，不能留在项目公司资产账里。

### 海洋服务

海洋服务不应只按能量卖电，而应写成关键负荷和应急保障能力。

建议写法：

1. 对海上平台、通信、监测、应急保障等刚性负荷收取服务费。
2. 把 ENS=0 作为服务等级指标，而不是免费可靠性约束。
3. 台风预警、过境和恢复阶段的保供能力可形成应急保障合同。

## 7. 调度模型需要同步优化

当前模型的优势是调度逻辑已经成型，但要支撑“收益转正”结论，需要从运行优化扩展到投资-运营联合优化。

建议新增四类模型能力：

1. 容量决策层：把风、光、潮、BESS、电解槽、储氢、海缆、算力容量从固定机制值改为候选容量，输出最优建设规模。
2. 资产边界层：区分自有资产、客户自持资产、租赁资产、共享基础设施和财政支持资产。
3. 合同层：加入 PPA、氢承购、算力容量费、海洋服务费、SLA 罚金封顶和调价条款。
4. 多年敏感性层：对 CAPEX、固定 O&M、融资率、电价、氢价、算力价格、利用率和台风年景做敏感性。

目标函数建议从单一 `economicNetCostCNY` 扩展为：

```text
minimize:
  年化自有资产成本
+ 固定运维
+ 替换准备金
+ 变量成本
+ 违约和缺供成本
- 合同收入
- 可确认补贴和容量服务收入
```

同时保留可靠性层级：

1. 刚性负荷 ENS=0 优先；
2. 台风预警和过境安全边界优先；
3. 合同保底交付优先；
4. 柔性算力、制氢和电力外送按边际收益排序；
5. 负边际收益产品自动退出。

其中，经济门槛和可靠性门槛要分开验收。30 MW PEM 可以作为经济试点，但如果目标是沿用当前年度 ENS=0 证据，氢转电短缺必须压到 0 MWh；否则就应明确写成“经济试点，不承担保供边界”。

## 8. CP01 申报材料可用正文

本项目拟构建面向深远海能源岛的多源协同调度与合同化收益闭环验证平台。平台以风、光、潮等海洋新能源为源侧基础，以 BESS、制氢储氢、柔性算力和海洋关键负荷为多端口消纳对象，通过 6 h 滚动先验-后验预测、可靠性-经济性分层优化和极端天气事件规则，实现新能源高比例消纳、关键负荷零缺供和多产品收益择优。

针对当前全量重资产方案项目层收益为负的问题，本方案不采用一次性满配建设路径，而采用“轻资产一期验证、合同化二期扩展、产业化三期放大”的分阶段实施路径。一期聚焦电力外送、关键负荷保障、小型储能和客户自持柔性算力，验证调度系统、收益闭环和台风事件韧性；二期在签订氢承购合同后，可先按 20 MW 到 30 MW 模块化电解槽验证交付现金流，但若项目评价要求继承当前年度台风代理事件 ENS=0 证据，则必须同步设置接近 100 MW 的制氢/储氢保供对照或等效外部备用；三期在取得潮流能 OEM 曲线、船运氢物流成本和海底算力长期容量租约后，再将潮流能、船运氢和规模化海底算力作为增量产业模块引入。

项目收益转正的关键不在单纯提高某一种产品价格，而在于把资产边界、合同收入和调度策略同时闭环。源侧和送出通道优先采用共建共享、PPA、CfD 或示范补贴机制，降低项目公司自有资本负担；海底算力由客户或设备商承担 IT 设备及替换成本，项目方提供绿电、冷却、舱体、运维和可中断调度服务；制氢业务只按实际交付确认收入，并通过 take-or-pay 或最低承购量合同锁定利用小时；海洋关键负荷和极端天气保供能力通过服务费或容量费体现其可靠性价值。

在技术评价上，项目以年度 8,760 h 连续仿真、多年随机资源序列和极端事件压力测试作为核心证据，重点考核新能源利用率、关键负荷 ENS、计划回退小时数、BESS 储备回退小时数、氢交付完成率、算力可中断服务量、合同收入覆盖率和年化资本负担覆盖倍数。只有当合同化年度毛收益覆盖项目实际承担年化负担并形成安全垫时，才进入下一阶段扩容。

## 9. 关键考核指标

| 类别 | 指标 | 建议门槛 |
|---|---|---:|
| 经济性 | 年度现金运行毛收益 / 实际承担年化负担 | >= 1.2 |
| 经济性 | 自有年化资本及固定负担下降幅度 | 一期 >= 80%，目标 >= 88% |
| 经济性 | 合同收入占总收入比例 | >= 70% |
| 经济性 | 一期转正边界 | >= 90% 年化负担下降，或 88% 下降下叠加足够合同收入 |
| 可靠性 | 关键负荷 ENS | 0 MWh |
| 可靠性 | 氢转电回放短缺 | 0 MWh 才能继承当前台风代理事件证据 |
| 可靠性 | 极端事件过境关键负荷服务率 | 100% |
| 调度质量 | 年度计划回退小时数 | 逐轮下降，需解释原因 |
| 调度质量 | BESS 储备回退小时数 | 逐轮下降，目标接近 0 |
| 资源利用 | 新能源利用率 | 不低于当前 73.046%，扩容后逐步提高 |
| 氢业务 | 氢交付收入确认率 | 只按实际交付确认 |
| 算力业务 | 客户自持或合同覆盖的算力 CAPEX 比例 | >= 80%，目标 100% |

## 10. 下一步落地清单

1. 获取赛题原文，确认是否要求实物建设、仿真平台、商业模式或示范应用。
2. 把当前固定资产边界拆成三套方案：全量重资产基准、一期轻资产方案、二期合同化扩展方案。
3. 在模型中加入资产所有权字段：自有、客户自持、租赁、共享、补贴覆盖。
4. 用企业报价替换漂浮式风电、海缆、换流站、BESS、PEM、储氢和算力 CAPEX。
5. 用合同价替换公开锚价：PPA 电价、氢承购价、算力容量费、海洋服务费。
6. 重跑 8,760 h 年度场景，输出每个阶段的现金毛收益、年化负担、转正倍数和敏感性。
7. 增加台风年、低风年、高弃电年、低电价年和设备故障年的压力测试。
8. 把氢库存终值从现金收入中剔除，只保留为资产状态和下一年度库存边界。
9. 对算力 SLA 罚金设置合同封顶和等级服务，避免用高罚金吞掉全部收益。
10. 形成提交包：技术路线、模型框架、实施路径、商业模式、KPI、风险与数据需求。

## 11. 最终建议

方案应把“重资产能源岛一次性建成”改成“可调度、可合同化、可分期扩容的深远海能源服务平台”。当前模型最有价值的成果不是证明满配资产一定赚钱，而是证明多产品调度和极端事件响应机制已经可运行。收益转正的关键，是把这套调度能力绑定到更轻的资产边界和更确定的合同收入上，同时把保供边界单独验收清楚。

一句话：先用轻资产和合同把现金流跑正，再用模型证明哪些资产值得扩容；30 MW 模块化制氢可以是经济试点，但不能直接当成当前 ENS=0 的保供边界；不要先把所有资产建满，再指望调度去弥补 35.75 亿元/年的缺口。
