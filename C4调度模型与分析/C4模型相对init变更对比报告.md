# C4 模型相对 init 版本变更对比报告


## 1. 总体结论

当前 C4 相对 init 的主要变化可以概括为：

1. **物理模型和 MILP 求解器没有发生实质性重写。**  
   V5 的源侧、储能、氢能、算力、输出通道、评价模块以及 MILP 建模/求解入口保持原有结构。

2. **活动 V5 模型的实际改动集中在经济参数和市场代理口径。**  
   电价、氢价、算力服务回退价格、BESS 终端价值等从旧的经验值或历史值，更新为公开市场代理值。

3. **C4 仓库结构做了大规模历史资料清理。**  
   大量 V4 历史归档、external 快照、旧输出结果、图片、MAT/CSV 文件被移除或不再作为运行依赖。该变化主要是仓库瘦身和责任边界整理，不代表活动模型公式被删除。

4. **第5章测试与验证层已从 C4 拆分到 C5。**  
   C4/V5 现在只承担模型基线、冻结接口、物理模块和求解内核责任；48 h 场景、年度场景、四方案对比、在线策略和结果管理由 `../C5/` 承担。

## 5. 口径变化

### 5.1 算力收益口径

init 中 `4.8` 的算力收益回退值为 `500 元/MWh-CS`。当前版本改为：

- 联合仿真优先读取 `4.6` 输出的逐时任务级收入；
- 只有缺少 `4.6` 经济序列时，才使用 `5000 元/MWh-CS` 的公开 GPU 租赁混合代理；
- 该回退值不覆盖任务级收入；
- 未交付服务不得计入收入；
- SLA 罚金和可变运维费单独计入。

### 5.2 内部电费口径

当前版本明确：

- `4.6` 输出的内部电费是内部转移价或机会成本；
- `4.8` 已在源侧计算发电成本；
- 因此 `4.8` 不应再次把内部电费加入项目总成本；
- 否则会造成重复计费。

### 5.3 市场价格性质

当前版本更明确地区分：

- 公开市场代理；
- 历史敏感性场景；
- 项目合同价；
- 企业待校准参数。

当前价格不能直接用于正式发布：

- 净利润；
- IRR；
- 投资回收期；
- PPA 收益；
- 绿证收益；
- 项目承购合同收益。

## 6. 未发生实质变化的模型部分

经文件差异核查，以下活动模型核心没有发生相对 init 的代码变化：

| 模块 | 判断 |
|---|---|
| 4.3 多源供给模型 | 未改动核心物理模型 |
| 4.4 母线功率平衡 | 未改动 |
| 4.5 储能/制氢/储氢模型 | 未改动 |
| 4.6 算力任务、PUE、SLA 主逻辑 | 未改动核心求解逻辑 |
| 4.7 电力外送、氢交付、海洋用能 | 未改动 |
| 4.8 多目标评价结构 | 结构未改，仅经济参数和说明变化 |
| V5 MILP 建模入口 | 未改动 |
| V5 求解器与审计逻辑 | 未改动 |
| V5 ε 约束框架 | 未改动 |

因此，当前版本不能表述为“调度物理模型被重新设计”。更准确的说法是：

> 当前版本在保持 V5 物理约束和 MILP 调度结构不变的前提下，更新了经济评价参数与市场代理口径，并清理了历史 V4 资料和非活动验证输出。

## 7. 对仿真结果的潜在影响

虽然物理模型未改，但经济参数变化可能影响调度结果和收益评价：

1. **电力收入提高**  
   电价从 347 元/MWh 更新到 401.34 元/MWh，电力外送收益增强。

2. **算力收入回退值显著提高**  
   缺少任务级收入时，算力从 500 元/MWh-CS 提高到 5000 元/MWh-CS，可能显著提高算力通道在经济评价中的权重。

3. **氢库存机会成本提高**  
   期初氢库存机会成本从 23.2 元/kg 提高到 28.36 元/kg，减少“免费使用初始氢库存”的低估风险。

4. **BESS 终端价值提高**  
   BESS 期末能量价值提高，会影响跨窗口库存保持和末端状态偏好。

5. **收益结论更依赖公开代理假设**  
   当前公开价格可以用于机制测试和敏感性分析，但不能替代项目实际合同、CAPEX/OPEX、融资和运维报价。

## 8. C4 与 C5 责任边界变化

当前文档明确：

- `C4调度模型与分析/V5模型/` 是唯一活动联合模型内核；
- `../C5/` 是唯一活动测试层；
- C5 负责 48 h 机制场景、四方案对比、年度场景、资产基准、在线策略和结果管理；
- C5 通过相对路径调用 C4/V5，不保存第二套 V5 副本；
- V4 整合和 external 只用于历史追溯，不参与运行。

这解决了 init 版本中历史资料、验证输出和活动模型混杂的问题，使当前仓库结构更清晰。

## 9. 汇报用结论

相对 `init` 版本，当前 C4 模型的主要改动不是物理模型重构，而是经济口径校准和项目结构整理。V5 的 MILP 调度内核、源储氢算用各物理模块、审计逻辑和接口责任边界基本保持不变；变化集中在电价、氢价、算力服务价格和库存机会成本等经济参数，且这些参数均被明确标注为公开市场代理或待企业校准值。与此同时，C4 清理了大量历史 V4 资料、external 快照和旧验证输出，并将第5章场景仿真与结果管理迁移到 C5，使 C4 只保留模型基线和求解内核责任。

正式表述建议：

> 本轮更新保持 C4/V5 的物理约束、MILP 优化框架和模块接口不变，主要完成了经济参数市场代理更新、算力收益口径修正、内部电费重复计费风险消除，以及 C4/C5 责任边界拆分。当前结果适合用于机制仿真和方案敏感性分析，但仍不能作为项目合同收益、正式投资回收期或融资级经济性结论。

## 10. 后续建议

1. 用相同输入分别在 init 和当前版本运行 V5，量化经济参数变化对调度结果和 KPI 的影响。
2. 对电价、氢价、算力价格做敏感性分析，避免单一公开代理价格主导结论。
3. 在获得企业合同价、CAPEX/OPEX、融资条件和 SLA 条款前，继续保留“公开代理/待校准”标注。
4. 若报告正文需要展示“模型改动”，应区分“运行内核未变”和“经济评价口径变化”，避免误写为物理模型重构。
